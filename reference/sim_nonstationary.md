# Simulated Data to Show a Non-stationary Example.

A simulated data set designed to show clear evidence of
non-stationarity. This simulated data is a set of 400 observations. The
data set is designed so that the left part of the study region has very
different overall variability from the right part of the study region.

## Usage

``` r
sim_nonstationary
```

## Format

A `tibble` object with 400 rows and 3 columns:

- x: an x-coordinate giving the x position of the data point.

- y: a y-coordinate giving the y position of the data point.

- response: the response variable of interest.
