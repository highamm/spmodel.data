# Acapori Trees in Plot 6 of the Paracou Research Station in French Guiana.

Point locations of Pogonophora schomburgkiana (common name Acapori)
obtained from the `Paracou6_2016` data set in the `vernabota` `R`
package. The plot dimensions are 250 by 250 (in meters).

## Usage

``` r
acapori
```

## Format

An `tibble` object with 118 rows and 6 columns:

- idTree: an identification number for the tree.

- Xfield: a horizontal x-coordinate for tree location.

- Yfield: a vertical y-coordinate for tree location.

- Lat: latitudinal coordinate for tree location.

- Lon: longitudinal coordinate for tree location.

- Circ: the tree circumference at 1.30 meters above ground, in
  centimeters.

## Source

The original source of the data can be found at
<https://paracou.cirad.fr/>. The data should be used for teaching and
illustrative purposes only.
