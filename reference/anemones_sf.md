# Anemone Locations in France.

Sea anemone locations in France. The data is an `sf` version of the
`anemones` data set in the `spatstat` package. The observation window of
the study area is a \[0, 280\] x \[0, 180\] rectangle.

## Usage

``` r
anemones_sf
```

## Format

A `sf` object with 231 rows and 2 columns:

- diameter: the diameter of the anemone.

- geometry: the point locations of the anemones in the study region.
