# Simulated Data to Help Interpret Poisson Regression Model.

A simulated data set designed to provide visualizations for interpreting
the estimated slope in a basic poisson regression model. This simulated
data is a set of 100 observations. The estimated slope from a poisson
regression assuming independence is positive.

## Usage

``` r
sim_poisson_pos
```

## Format

A `tibble` object with 100 rows and 2 columns:

- x: a quantitative predictor variable.

- response: the response variable of interest.
