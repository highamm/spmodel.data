# Dataset Information

The following table shows the non-simulated data sets in this package,
along with a short description and the use-case of the data sets. These
data sets are used the textbook *Foundations of Spatial Statistics*
(working title) by Matt Higham and Michael Dumelle (Taylor & Francis CRC
Press, August 2027).

For any data sets used, please cite the original source of the data
(found in `Source` and/or `References` in at the bottom of the help page
`?name_of_data_set`). Thank you in advance for giving proper credit to
those who have collected and/or curated this data!

Many of these data sets can be analyzed using functions from the
`spmodel` `R` package: <https://usepa.github.io/spmodel/> (citation
below).

Dumelle M, Higham M, Ver Hoef JM (2023). `spmodel`: Spatial statistical
modeling and prediction in R. *PLOS ONE* 18(3): e0282524.
<https://doi.org/10.1371/journal.pone.0282524>.
