# Simulated Locations Corresponding to a Random Planar Point Pattern.

The data set contains simulated locations from a random planar point
pattern on a diamond.

## Usage

``` r
diamond
```

## Format

An `sf` object with 130 rows and 3 columns:

- x_loc: the x-location of the point.

- y_loc: the y-location of the point.

- geometry: the coordinates for the point.
