# Simualted Data for Assessing Stationarity.

A simulated data set designed to show how the stationarity assumption
can be fully assessed with a very large data set. This simulated data is
a set of 1600 observations.

## Usage

``` r
sim_quadrants
```

## Format

A `tibble` object with 1600 rows and 3 columns:

- x: an x-coordinate giving the x position of the data point.

- y: a y-coordinate giving the y position of the data point.

- response: the response variable of interest.
