# Simulated Data for Preferential Sampling Illustration.

A simulated data set designed to show consequences of preferential
sampling. This simulated data is a set of 200 spatial locations that we
could sample from.

## Usage

``` r
sim_preferential
```

## Format

A `tibble` object with 200 rows and 4 columns:

- x: an x-coordinate giving the x position of the data point.

- y: a y-coordinate giving the y position of the data point.

- x1: an indicator variable serving as a possible predictor.

- response: the response variable of interest.
